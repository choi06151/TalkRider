# 토크라이더 (TalkRider)

운전자와 동승자가 **말 한마디로** 시작하는 차량용 음성 대화 서비스입니다.
도착만 기다리던 이동 시간을, 함께 웃고 이야기하는 시간으로 바꾸는 것을 목표로 합니다.

현대자동차그룹 차량용 앱 개발 공모전(Pleos Playground) 출품 프로젝트입니다.

**프로토타입 바로 보기:** https://choi06151.github.io/TalkRider/
(PC의 Chrome 또는 Edge 브라우저를 권장합니다. 음성 기능은 마이크 허용이 필요합니다.)

## 어떤 서비스인가요

가족이나 친구와 차로 이동하다 보면 대화가 끊기고, 각자 휴대폰을 보거나 잠이 들기 쉽습니다. 운전자는 화면을 조작할 수 없어 대화에 끼기도 어렵습니다.

토크라이더는 AI가 이동 상황에 맞는 질문과 놀이를 먼저 던져, 탑승자가 따로 준비하지 않아도 대화를 시작하고 이어가도록 돕습니다.

- **음성 중심:** 시작, 답변, 패스, 일시정지, 이어하기, 종료를 모두 말로 합니다. 운전자는 화면을 만질 필요가 없습니다.
- **점수·레벨·시간제한 없음:** 이기고 지는 게임이 아니라, 대화를 여는 질문을 자유롭게 즐기는 방식입니다.
- **이동 맞춤 질문:** 목적지와 남은 시간, 휴게소 접근 같은 이동 상황에 맞춰 질문과 미션을 제안합니다.
- **동승자 설정:** 쉬고 싶은 사람은 빼고, 참여하고 싶은 사람끼리 즐길 수 있습니다.
- **여행 기록과 엽서:** 오늘의 하이라이트를 모아 보고, 디지털 엽서를 QR로 휴대폰에 저장해 공유합니다.

## 이런 순간에 사용해요 (강릉 여행 예시)

1. 출발 전 정차 중에 좌석별 닉네임과 참여 여부를 정합니다.
2. 주행 중 AI가 "강릉에 도착하면 조개구이와 회 중 뭐부터 먹을까요?"처럼 묻고, 두 사람이 각자 고른 이유를 이야기합니다.
3. 대화가 잦아들면 "다른 놀이 해줘"로 놀이를 바꿉니다.
4. 운전에 집중해야 할 때는 "잠깐 멈춰", 여유가 생기면 "계속하자"로 이어갑니다.
5. 도착 후 "오늘 기록 보여줘"로 하이라이트를 확인하고 엽서를 QR로 저장합니다.

## 프로토타입 사용법

배포 링크를 열면 시작 화면에서 바로 체험할 수 있습니다. 화면은 앱의 전체 흐름(IA)과 놀이별 진행 흐름 순서로 이어지는 웹 프로토타입입니다.

- 카드, 버튼, 상단 탭(홈·놀이·기록·설정)을 누르면 다음 화면으로 이동합니다.
- 놀이 화면에서는 본문이나 "패스", "다음 문제" 같은 음성 명령 버튼을 누르면 다음 단계로 넘어갑니다.
- 놀이 중 "멈춤"으로 일시정지하고 이어할 수 있고, 앱을 종료하면 진행 상황이 저장되어 다시 열었을 때 이어집니다.
- 키보드: 왼쪽 방향키와 Esc는 뒤로, 오른쪽 방향키는 다음 화면입니다.
- 설정의 "마이크 테스트"를 켜면 음성 명령("다음", "이전", "잠깐", "이어서", "놀이 시작")을 쓸 수 있습니다.
- 안내 음성은 브라우저에 내장된 음성 중 남성 목소리를 먼저 고릅니다. Edge에서 가장 자연스럽고, Chrome에서는 한국어 남성 음성이 없어 다른 음성으로 대체될 수 있습니다. 주소 뒤에 `?voice=Hyunsu`처럼 붙이면 음성을 직접 고를 수 있습니다.

> 이 프로토타입은 화면 흐름과 음성 인터랙션을 보여 주기 위한 웹 버전이며, 실제 차량 연동은 아래 개발 계획에 따라 진행합니다.

### 엽서를 QR로 휴대폰에 받기

QR 화면은 휴대폰이 PC에 접속해야 하므로, PC에서 서버를 띄워 시연합니다.

```
node prototype/serve.js
```

1. 휴대폰과 PC를 같은 Wi-Fi에 연결합니다. (Windows 방화벽 창이 뜨면 "개인 네트워크"를 허용합니다.)
2. PC 브라우저로 터미널에 표시된 주소(`http://localhost:5173/`)를 엽니다.
3. 여행 엽서의 "QR로 받기" 화면에서 QR을 휴대폰 카메라로 찍으면 `postcard.html`이 열리고, "이미지 저장"으로 엽서 앞면·뒷면을 사진에 저장할 수 있습니다.

## 개발 계획 (Pleos Connect)

Pleos Connect(Android Automotive OS 기반) 환경에서 Pleos Connect Emulator로 개발하고 검증할 계획입니다.

| SDK / 인터페이스 | 활용 계획 |
|---|---|
| SpeechToText SDK | 답변, 패스, 일시정지, 종료 등 음성 입력을 텍스트로 변환 |
| TextToSpeech SDK | AI가 질문과 규칙 설명을 음성으로 읽어 차량 오디오로 재생 |
| Gleo Interface | App Schema를 등록해 "다른 놀이 해줘", "잠깐 멈춰" 같은 명령 발화를 Gleo AI가 앱 기능으로 호출 |
| NaviHelper SDK, FusedLocation SDK | 목적지, 경로, 현재 위치로 휴게소·목적지 접근 시점에 맞는 질문 제안 |
| Vehicle SDK | 주차 브레이크와 주행 모드로 정차와 주행을 구분 |

안전을 위해 Pleos App Market의 운전자 주의 분산 최소화 기준을 따릅니다. 주행 중에는 화면 조작 없이 음성 중심의 최소 정보 화면만 제공하고, 설정과 기록 확인은 정차 중에만 허용합니다. 차량 API와 권한은 Pleos App Market에서 승인된 범위 안에서만 사용합니다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `prototype/CAR_PLAYGROUND_prototype.html` | 웹 프로토타입 (HTML 파일 하나, 이미지는 `prototype/img/`) |
| `prototype/postcard.html`, `prototype/postcards/` | 여행 엽서 페이지와 엽서 이미지 |
| `prototype/serve.js` | 엽서 QR 시연용 로컬 서버 |
| `questions/` | 문항 데이터 (`catalog.json`은 문항 유형 카탈로그, `common`·지역별 문항 JSON) |
| `questions/validate_questions.py` | 문항 형식 검증 스크립트 |
| `PLAN_기획서.md` | 기획서 |
| `GDD_CAR_PLAYGROUND.md` | 제품 설계서 |
| `QUESTION_DB.md` | 문항 DB 가이드 |

문항 검증은 아래 명령으로 실행합니다.

```
python questions/validate_questions.py questions
```

## 현재 상태와 한계

- 프로토타입은 화면 흐름과 음성 인터랙션 시연용이며, 실제 차량 연동은 아직 구현 전입니다.
- 사실형 문항(상식, 숫자, 가격)은 출처 확인 전 샘플(`sample:true`)입니다.
- 소리 놀이용 음원은 확보 후 활성화할 예정입니다.
- 이전 게임형 프로토타입(v0.x)은 git 기록에 남아 있습니다.
