# CAR PLAYGROUND

현대자동차그룹 차량용 앱 개발 공모전(Pleos Playground) 출품 프로젝트. 동승자 성인 2~5명이 화면 없이 말로 즐기는 차 안 대화 애플리케이션. 점수, 레벨, 시간제한이 없고 자유 모드로 이용한다. 목적지와 남은 시간은 차량(내비) API에서 자동으로 받는다.

## 프로토타입 열기
`prototype/CAR_PLAYGROUND_prototype.html`을 브라우저로 연다(`prototype/img/` 폴더가 옆에 있어야 한다). 화면은 Figma `Page 5` 프레임 132개를 레이어 그대로(글자 크기·폰트·이미지 배치) 옮긴 것이고, IA(전체 앱 흐름 · 게임별 진행 흐름) 순서로 이어진다. 휴대폰 이미지 저장 화면만 Page 5에 없어 이전 화면을 쓴다.
- 카드·버튼·상단 탭(홈·놀이·기록·설정)을 누르면 다음 화면으로 간다. 게임 화면은 본문이나 “패스”·“다음 문제” 같은 음성 명령 버튼을 누르면 다음 단계, 인트로는 4초 후 자동 시작. 게임마다 여러 판을 거쳐 그 게임의 “종료” 화면으로 끝난다.
- 공통 음성 상태(프레임 이름 그대로):
  - V02 일시정지: 게임 중 “멈춤”(또는 P 키). 차량 안내가 끝나면(4초) V03으로.
  - V03 음성으로 이어하기: “이어서 해줘” → 멈춘 문제·차례로, “그만할래” → V05 놀이 종료.
  - V04 다시 말하기: AI가 말을 알아듣지 못했을 때(마이크 켠 상태에서 알 수 없는 말, 시연은 R 키). 본문 → 같은 문제 다시, “패스” → 다음 문제, 7초 응답 없으면 V02.
  - 게임 끝: 각 게임의 종료 화면 → “기록 보여줘” 그 게임의 오늘의 놀이 기록 · “다른 놀이” 게임 목록.
  - V07 저장한 놀이 이어하기: 게임 중 하단 차량 바의 다른 앱(내비·음악·전화 등)을 누르면 저장 후 앱을 나가고, 다시 앱을 열면(스플래시 또는 차량 바의 앱 아이콘) 이 화면에서 “이어서 하기”.
- 놀이 준비의 “목적지까지 놀이”: 빈 상태 → 놀이 담기 / 빼기(✕) / 🎲 랜덤 채우기 화면으로 바뀐다. 설정의 좌석 “삭제” → 삭제 확인 후 인원이 준다.
- 음성 바 왼쪽 아이콘은 홈·놀이·기록.
- 왼쪽 위 뒤로가기 버튼(또는 ← / Esc)은 지나온 화면으로, 바로 연 화면이면 위 단계 화면(게임은 이전 단계)으로 간다. → 다음.

- 동승자 프로필 아이콘을 누르면 “프로필 아이콘 설정” 팝업(아이콘 20종 · 닉네임)이 뜨고, 저장하면 모든 화면의 그 동승자 아이콘이 바뀐다. 인원·관계·닉네임도 한 화면에서 바꾸면 모든 화면에 반영된다.
- 놀이 준비 → 게임별 시작 대기 → 인트로, 오늘의 기록은 게임별 기록 화면(R02-1~8)으로 이어진다.
- 여행지 사진(이동 정보·여행 엽서·지난 기록·홈)은 화면에 적힌 목적지 이름을 보고 `prototype/destinations/<영문>.jpg`에서 자동으로 고른다. 강릉·춘천·여수·부산·속초·통영·해운대·가평 8곳, Figma AI로 생성한 실사 이미지. 새 목적지는 사진을 넣고 router의 `DEST_PHOTO`에 이름을 추가한다.

### 엽서 QR로 휴대폰에 받기
휴대폰이 PC에 접속해야 하므로 서버로 띄운다.
```
node prototype/serve.js
```
1. 휴대폰과 PC를 같은 Wi-Fi에 연결한다. (Windows 방화벽 창이 뜨면 "개인 네트워크" 허용)
2. PC 브라우저로 터미널에 찍힌 주소(`http://localhost:5173/`)를 연다.
3. 여행 엽서 → QR로 받기 화면의 QR은 PC의 Wi-Fi 주소로 자동 생성된다. 휴대폰 카메라로 찍으면 `postcard.html`이 열리고, “이미지 저장”으로 엽서(앞면·뒷면)를 사진에 저장한다.
- 엽서 이미지: `prototype/postcards/` (Figma Page 5 엽서를 반듯하게 2배 해상도로 내보낸 것)
- QR 생성: `prototype/vendor/qrcode.js` (qrcode-generator, MIT)
- 파일을 그냥 열거나 서버 없이 열면 QR은 보이지만 휴대폰에서는 열리지 않는다. 설정의 “마이크 테스트”로 음성 명령(“다음” “이전” “잠깐” “이어서” “놀이 시작”)을 켠다.
- 안내 음성은 브라우저 내장 음성 중 **남자 목소리**를 먼저 고른다. **Edge**로 열면 신경망 남성 음성 “InJoon / Hyunsu Online (Natural)”이 나와 가장 자연스럽다. 크롬에는 한국어 남자 음성이 없어 “Google 한국의”(여성)로 대체되고 안내 문구가 한 번 뜬다. 주소 뒤에 `?voice=Hyunsu`처럼 붙이면 음성을 직접 고를 수 있다.
